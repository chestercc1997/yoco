下面统一用第 1–6 层作为来源，第 7–12 层共享融合后的 K/V。

① 多层 K/V 的加权聚合：每一层贡献多少。

记 K_{t,j},V_{t,j} 是位置 t、来源层 j 提供的候选记忆。聚合公式为：

┌─────────────────────────────────────────────────────────┐
│          6                            6                 │
│  Kₜ^{*}= ∑ α_{t,j}K_{t,j},   Vₜ^{*}=  ∑ α_{t,j}V_{t,j}  │
│         j=1                          j=1                │
└─────────────────────────────────────────────────────────┘

其中：

              6
α_{t,j}≥ 0,   ∑ α_{t,j}=1.
             j=1

展开就是：

Kₜ^{*} =α_{t,1}K_{t,1} +α_{t,2}K_{t,2} +⋯ +α_{t,6}K_{t,6}.

这里的加号就是直接聚合，α_{t,j} 就是该 token 对第 j 层的动态占比。 初版让 K、V 共用这套权重即可。

但这条公式只规定“如何组合”，还需要定义权重从哪里来。

② Conditional 权重：根据 hidden states 决定各层占比。

采用类似 attention 的方式，给同一个 token 在不同深度的表示打分：

Ĥ_{t,j}=RMSNorm(H_{t,j}),

┌─────────────────────────────────────────────────────────────┐
│           w^{⊤}Ĥ_{t,j}                   exp(s_{t,j}/τ)     │
│  s_{t,j} =────────────+bⱼ,   α_{t,j} = ───────────────────  │
│               √(d)                     ∑ᵢ₌₁⁶exp(s_{t,i}/τ)  │
└─────────────────────────────────────────────────────────────┘

这里：

- w：可学习的打分向量，判断当前来源的内容是否适合写入记忆。
- bⱼ：可学习的层偏好。
- τ：控制权重分布的温度，初版可以固定为 1。
- softmax 在六个来源层之间进行。

参数 w,b 通过训练学习；实际占比 α_{t,j} 则随 token 的 hidden states 改变。 所以这就是 conditional，而不是所有 token 使用一套固定比例。

把两部分合起来，就是我们要实现的公式：

\[
\boxed{
\begin{aligned}
\alpha_{t,j}
&=\operatorname{softmax}_{j}
\left(
\frac{w^\top\operatorname{RMSNorm}(H_{t,j})/\sqrt d+b_j}{\tau}
\right),\\
K_t^*&=\sum_{j=1}^{6}\alpha_{t,j}K_{t,j},\\
V_t^*&=\sum_{j=1}^{6}\alpha_{t,j}V_{t,j}.
\end{aligned}
}
\]

这是对 ABC 思路的一种具体实现，不表示他规定了唯一的打分函数。

后续第 7–12 层怎么使用？

融合在进入第七层之前完成一次。后六层各自生成 Q，读取同一份融合记忆：

\[
\boxed{
A_{t,\ell}
=\operatorname{softmax}_{s\leq t}
\left(
\frac{Q_{t,\ell}(K_s^*)^\top}{\sqrt{d_h}}
\right)V_{\leq t}^*,
\qquad \ell=7,\ldots,12.
}
\]

式中 softmax 的结果是对历史位置的权重；后面接各层自己的输出投影、残差和 FFN。这里不再按读取层重新生成融合权重。

为什么它可能比逐步 gate 构建 memory 更好传梯度？

对照的递归门控可以写成：

Mⱼ=(1-gⱼ)Mⱼ₋₁+gⱼUⱼ.

展开后，第 j 个来源对最终 M₆ 的贡献系数是：

┌───────────────────┐
│  gⱼ∏ₖ₌ⱼ₊₁⁶(1-gₖ)  │
└───────────────────┘

也就是：早期来源需要经过一串后续 gate。当这些因子持续小于 1 时，这条直接路径可能明显衰减。

而我们的直接聚合是：

              ┌────────────────────────────────┐
   6          │   ∂ℒ                      ∂ℒ   │
M= ∑ αⱼUⱼ,    │  ────|_{直接聚合路径} =αⱼ ───  │
  j=1         │  ∂ Uⱼ                     ∂ M  │
              └────────────────────────────────┘

这里暂时固定权重来观察直接路径。每个来源只乘自己的聚合权重，不需要再乘后续层的一串 memory gate。 动态权重本身还有经 hidden states 反传的梯度。

因此可以准确地表述为：条件化的多层 K/V 直接聚合，为各来源提供了更直接的梯度路径，避免了递归 memory 更新在这条路径上的连续门值乘积；但小权重、softmax 饱和以及原网络中的梯度问题仍可能存在，收敛收益需要实验验证
